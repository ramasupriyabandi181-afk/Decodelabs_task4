# Image or Text Recognition using Python

## Project Description
This project uses Optical Character Recognition (OCR) to extract text from an image using Python. It uses Tesseract OCR and OpenCV to process the image and recognize the text.

## Technologies Used
- Python
- OpenCV
- Tesseract OCR
- Pytesseract
- Pillow

## Working
1. Load the input image.
2. Convert the image into grayscale.
3. Apply Gaussian blur to reduce noise.
4. Convert the image into black and white using thresholding.
5. Extract text using Tesseract OCR.
6. Display the recognized text and processed image.

## Installation
Install the required Python libraries:

```bash
python -m pip install pytesseract opencv-python pillow
```

Install Tesseract OCR separately on Windows.

## How to Run
1. Place `input.png` in the project folder.
2. Open the terminal in the project folder.
3. Run:

```bash
python main.py
```

## Sample Output

```text
Recognized Text:
Artificial Intelligence
Project 4
Text Recognition using Python
```

## Conclusion
The project successfully extracts text from an image using OCR and demonstrates basic image preprocessing techniques.
